# VirelleaNotesEngine

> 自作ゲームで使う譜面データをGUIで誰でも作成できる、譜面エンジンです。

自作の音楽ゲームで使う譜面データを作成できます。
※まだまだリファクタリングとバグの除去・調整など課題はありますが、現状使うことはできます。

## 特徴

- GUIで誰でも簡単に譜面を作ることができる。
- 好きな音源を入れてBPMさえわかれば好きに音源から譜面を作成できる。

## 使用技術

- C++
- DXライブラリ
- 音源操作
- CSVの入出力
- 再生時間とBPMに合わせたグリッド描画

## インストール

```bash
プロジェクトファイルをクローンして、サンプル.slnを開き実行・ビルドしてください。
※exe用のブランチも追加予定です。
```
